# Plan: Describe therapies

## 1. Define therapy data

1. Define a TypeScript type for a therapy with the fields agreed for this phase.
2. Add one fictional therapy to local data.
3. Associate the therapy with a relevant ailment.

## 2. Present therapies

1. Show therapy names and descriptions in the relevant agent or ailment view, as agreed.
2. Show a useful empty state when no therapies are available.
3. Keep content semantic, keyboard accessible, responsive, and consistent with the existing app.

## 3. Validate and hand off

1. Confirm the therapy and its ailment association are clear in the UI.
2. Confirm the no-therapies state is clear.
3. Check keyboard access and narrow/wide layouts.
4. Run the project build and record the command and result in the implementation handoff.
